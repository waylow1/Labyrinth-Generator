\doxysubsection{Detailed Description}
SDL rendering and player movement controls for the labyrinth game. 

Provides drawing helpers, keyboard input orchestration, time/score UI, and high-\/level movement rules (keys, doors, chests, traps, monsters).

\begin{DoxyNote}{Note}
If the player moves onto a key (KEY), they acquire it. 

If the player moves onto a chest (CHEST), 1000 coins are added. 

If the player moves onto a trap (TRAP), 500 coins are subtracted. 

Movement into a wall (WALL) is blocked. A door (DOOR) is passable if the player holds the key; stepping onto it unlocks the door. 
\end{DoxyNote}
