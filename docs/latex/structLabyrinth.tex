\doxysubsection{Detailed Description}
Full labyrinth grid and runtime state. 

The grid uses a scaled representation of size (2\texorpdfstring{$\ast$}{*}length+1) x (2\texorpdfstring{$\ast$}{*}width+1) where walls are placed at even coordinates and paths/objects at odd coordinates.
