\chapter{Labyrinth Generator}
\hypertarget{index}{}\label{index}\index{Labyrinth Generator@{Labyrinth Generator}}
\label{index_md_docs_2mainpage}%
\Hypertarget{index_md_docs_2mainpage}%
 A small C + SDL2 project that generates, plays, and documents mazes. It features Easy/\+Hard difficulty, optional monsters with function-\/pointer AI, a simple score ladder, and a unit test suite.\hypertarget{index_autotoc_md1}{}\doxysection{\texorpdfstring{Features}{Features}}\label{index_autotoc_md1}

\begin{DoxyItemize}
\item Maze generation (Kruskal-\/like) with objects (player, exit, door+key, chests, traps)
\item Difficulty modes (Hard\+: extra loops + monsters)
\item Monsters (ghosts/ogres) with behavior via function pointers
\item Config I/O (seed, size, difficulty) and score persistence
\item SDL rendering (grid, time, points) + ASCII debug displays
\item Unit tests (minunit)
\end{DoxyItemize}\hypertarget{index_autotoc_md2}{}\doxysection{\texorpdfstring{Project Layout}{Project Layout}}\label{index_autotoc_md2}
